# Chunk quality

Metrics are computed from the included manifest sources. Counts are generated by this run.

A (`recursive`) uses 800 characters with 100 characters of overlap. B (`blocks`) targets 450 tokens without overlap, carries the document/section prefix, keeps each table atomic, and splits oversized code blocks on line boundaries. An 8-token reserve accounts for tokenization changes when the prefix and body are joined.

The USD estimate uses $0.02 per 1M input tokens for the selected `text-embedding-3-small` model per the [official OpenAI pricing page](https://developers.openai.com/api/docs/pricing/). It is a planning estimate, not an API-reported or billed amount; it excludes retries and Qdrant charges. The quality calculation itself makes no embedding or Qdrant write calls.

`tables_in_multiple_chunks` and `tables_missing_introduction` must remain 0 for B. The introduction check applies when the source paragraph immediately before a table ends with a colon. Tables exceeding 450 tokens are intentionally kept whole and reported in `oversized_table_chunks`. `duplicate_sentences` counts repeated long sentences within a source; it can reflect authored repetition as well as overlap. `header_footer_lines` is a page-boundary heuristic; review the reported PDF counts against representative page boundaries before changing the cleaning rules. Only extractable text is measured; figure/image contents are not embedded.
